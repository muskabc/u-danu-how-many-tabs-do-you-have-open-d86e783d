# How Many Tabs Do You Have Open?

**137**

One hundred and thirty-seven tabs. Not a round number, not a guess — the honest count.

The story behind it: this is a browser that has become a second memory. There are half-read research papers from three projects ago, a dozen "read later" articles dating back to the spring, bounty pages and documentation left open mid-task, a recipe tab from last Tuesday's dinner, and at least twenty tabs kept open "just in case" that nobody has looked at in weeks. Nothing is ever closed, because closing a tab feels like admitting the thing behind it will never happen. So they pile up — 137 small open loops, each one a promise to a future self.

## How it works

`main.ts` reads the count from `line.txt`, checks it is exactly one number of 1–5 digits, and writes it to `entry.txt` in the output directory (`$MAKEFUN_OUTPUT_DIR`, or `/output` by default), with no trailing newline.

```sh
node main.ts
```
